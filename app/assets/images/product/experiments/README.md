# DUWZGU experimental product imagery

The unreferenced image files were removed from the deployed assets during the
September 2026 cleanup. They remain recoverable from Git history. The notes below
describe those archived concepts; see docs/NETTOYAGE_IMAGES.md for the inventory.

## Production candidates

- `duwzgu-concept-strawberry-frozen`: vertical luxury ice/crystal product card.
- `duwzgu-concept-blueberry-gym`: vertical, authentic post-workout gym scene.
- `duwzgu-concept-raspberry-lab`: vertical futuristic magenta studio scene.

Suggested slots: editorial cards, product-story bands, mobile campaign panels,
or flavor-specific alternatives selected through `Flavor`.

## Layout drafts

- `duwzgu-concept-trio-neon-runway-draft`: extra-wide banner with copy space left.
- `duwzgu-concept-trio-gym-draft`: wide lifestyle image with copy space right.
- `duwzgu-concept-trio-neon-rings-draft`: square flavor-selection or social card.

The trio images are composition drafts. Generative rendering can distort the
small dosage/count copy on labels, so those details must be corrected or replaced
with exact packshot composites before production advertising.

## Prompt set

All six concepts used the built-in image generation workflow with the existing
DUWZGU package images as exact product references. Shared constraints were:

> Preserve the jar, black lid, DUWZGU identity, flavor color and label layout;
> deep black premium sports-nutrition art direction; crisp label light; no added
> headline, watermark, cropped jar or duplicate flavor.

The scene directions were, respectively: frozen crimson crystal; industrial gym;
magenta performance lab; minimal three-color obsidian runway; post-workout gym
bench; and smoked-glass neon flavor rings.
